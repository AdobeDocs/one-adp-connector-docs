# Get started

The Adobe for Developers plugin brings common Adobe developer workflows into Claude. Once installed, you can search Adobe's developer documentation, manage your [Developer Console](https://developer.adobe.com/console/) projects and APIs, and set up Adobe I/O Events — all through natural language.

## Install the plugin

Install the plugin in your client of choice to get started. Each guide walks through the full installation for a specific client:
